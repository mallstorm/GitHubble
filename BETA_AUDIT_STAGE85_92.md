# GitHubble 0.27.0 — beta audit

## Закрыто в проходе 85–92

- Replay-safe офлайн-очередь без токенов.
- Версионная проверка и ручное разрешение конфликтов.
- Создание repository/fork/branch/tag/Release.
- PR line comments, suggested changes, checks и required checks.
- Unified/Split diff с навигацией и сворачиванием контекста.
- Безопасный preview для текста, изображений, SVG, PDF и бинарных файлов.
- Перенос локальных пользовательских данных без секретов.
- Вынос нового предметного функционала в отдельные контроллеры и state-модель.

## Риски beta

1. Разрешения GitHub App должны быть проверены на реальной установке GiHubble.
2. Offline replay и конфликты требуют теста с реальным прерыванием сети.
3. Suggested changes и line comments нужно проверить на PR с изменениями обеих сторон diff.
4. Большие изображения и diff требуют профилирования памяти на устройствах API 28.
5. Исторические экраны MainActivity ещё не полностью разнесены по отдельным screen-классам.

## Решение

Статус: beta build для тестового устройства. До stable 1.0 необходимы этапы 93–100 и реальная device matrix.
