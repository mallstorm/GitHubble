---
name: code-review
description: Ревью изменений или PR: корректность, риски, тесты
---
1. pull_request_details / файлы PR (repository_read_file) или локальные изменения (changes_status).
2. Проверяй по порядку: корректность и граничные случаи, безопасность (секреты, ввод), совместимость, тесты, стиль проекта (HUBBLE.md).
3. Ответ: сначала главное (блокирующие проблемы), потом замечания и предложения. Конкретные места: файл и строка.
4. Не меняй код без просьбы; комментарий в PR — comment_issue только по согласию.
