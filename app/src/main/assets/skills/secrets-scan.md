---
name: secrets-scan
description: Поиск утёкших секретов в репозитории и истории
---
1. Ищи по коду шаблоны токенов, ключей, паролей, приватных ключей и .env-файлов (search_files).
2. Проверь github_get /repos/{o}/{r}/secret-scanning/alerts, если доступно.
3. Для каждой находки: где, что за тип, активен ли. Значения секретов в ответ не копируй — только маски.
4. Дай порядок действий: отозвать ключ у провайдера, заменить, убрать из кода, добавить в .gitignore. Переписывание истории — только с явного согласия пользователя.
