---
name: repo-cleanup
description: Навести порядок в репозитории: старые ветки, закрытые PR, лишние релизы
tools: github_request, actions_cleanup
---
1. Прочитай состояние: repository_branches, repository_pulls, list_releases (github_get для остального).
2. Составь список кандидатов на удаление: ветки без открытого PR и старше 30 дней, влитые ветки, черновые релизы. Основную ветку и ветки с открытым PR не трогай.
3. Покажи пользователю список целиком с причинами (ask_user: «Удалить всё» / «Выбрать» / «Отмена»).
4. Удаляй по одной через github_request DELETE /repos/{o}/{r}/git/refs/heads/{ветка}; каждое удаление подтверждает хост.
5. Отчёт: сколько удалено, что пропущено и почему.
