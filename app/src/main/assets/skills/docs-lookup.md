name: docs-lookup
description: Найти точный ответ в официальной документации (API, библиотека, команда, ошибка)
---
1. Определи продукт и версию (из проекта: build.gradle, package.json, manifest). Версию упоминай в ответе.
2. web_research {query} на английском с именем продукта и точным термином/текстом ошибки; затем web_fetch {url} для нужной страницы документации.
3. Если доки на JS-сайте и текст пустой — cloud_browser {url}.
4. Дай ответ: сигнатура или команда, минимальный рабочий пример, ограничения и версия, ссылка на страницу. Не придумывай параметры, которых нет в документации.
5. Если ответ меняет код проекта — предложи изменение, но не применяй без просьбы.
