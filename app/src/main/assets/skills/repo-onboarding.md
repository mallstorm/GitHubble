---
name: repo-onboarding
description: Быстро разобраться в чужом репозитории: о чём проект, как устроен, как запустить, где точки входа
---
1. focus_repository на репозиторий, затем README (repository_read_file), корень (repository_files), workflows и недавние коммиты.
2. Определи стек по манифестам (package.json, build.gradle, pyproject.toml, Cargo.toml, go.mod) и точки входа.
3. Ответ короткий: о чём проект (1–2 предложения), стек, структура по папкам, как собрать и запустить (из README и CI), состояние (активность коммитов, открытые issues).
4. Если README на иностранном языке — перескажи по-русски. В конце предложи до трёх следующих шагов (ask_user).
