---
name: cloud-export
description: Выгрузить файлы проекта, отчёты или заметки в облако
---
1. cloud_sources {}: выбери облако (если их несколько и пользователь не указал — спроси через ask_user).
2. Для файла из проекта: cloud_upload {source,path:"Папка/имя.ext",from:"путь/в/проекте"}. Для текста, который ты подготовил (отчёт, список, summary): cloud_upload {source,path:"Папка/имя.md",content}.
3. Файл с тем же именем в облаке будет заменён — карточка подтверждения скажет об этом; для важных файлов добавь дату в имя (report-2026-11-25.md).
4. Не загружай секреты, ключи, .env и keystore. Если такие файлы попросили выгрузить — предупреди и уточни.
5. После загрузки назови облако, папку и имя файла.
