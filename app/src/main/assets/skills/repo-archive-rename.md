---
name: repo-archive-rename
description: Переименовать, архивировать или передать репозиторий без потери ссылок
tools: github_request, update_repository
---
1. Покажи последствия: редиректы GitHub, ссылки в README и workflow, клоны у других людей.
2. Спроси подтверждение (ask_user), затем выполни операцию; хост покажет отдельную карточку.
3. После переименования найди и обнови старые ссылки в коде и документации.
4. Архивация обратима, удаление нет — не заменяй одно другим без согласия.
