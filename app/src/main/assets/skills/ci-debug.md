---
name: ci-debug
description: Разобрать упавшую сборку: причина, исправление, повторный запуск
---
1. recent_build_runs → build_run_diagnostics для упавшего запуска (логи только с согласия пользователя: ci_failure include_logs).
2. Определи класс ошибки: код, окружение, права, биллинг. Окружение, права и биллинг кодом не лечатся — сообщи пользователю.
3. Для ошибки кода: найди файл (repository_read_file / search_files), предложи минимальную правку, покажи diff и вносить только после согласия.
4. После публикации правки: дождись нового запуска (await_build) и сообщи итог фактами из GitHub, а не предположением.
