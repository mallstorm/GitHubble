---
name: security-review
description: Проверка безопасности репозитория: права, секреты, зависимости, защита веток
---
1. github_get: /repos/{o}/{r}/branches/{main}/protection, /rulesets, /actions/permissions, /collaborators, /dependabot/alerts, /code-scanning/alerts, /actions/secrets (только имена).
2. Отметь риски: нет защиты основной ветки, лишние коллабораторы, секреты в старых коммитах (по подсказкам пользователя), устаревшие зависимости.
3. Изменения прав и защиты — только через github_request: хост потребует от пользователя ввести точное имя. Объясни последствия до вызова.
4. Итог: список находок по важности и что предлагаешь исправить первым.
