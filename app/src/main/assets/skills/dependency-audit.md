---
name: dependency-audit
description: Проверить зависимости проекта: устаревшие, уязвимые, лишние, совместимость версий
---
1. Найди манифесты (package.json, build.gradle, pom.xml, requirements.txt, Cargo.toml, go.mod) и lock-файлы.
2. Составь список прямых зависимостей с версиями. Актуальные версии и известные уязвимости ищи через web_research (страница пакета, advisory, changelog).
3. Ответ таблицей: пакет, текущая, актуальная, риск (критично/желательно/ок), что сломается при обновлении.
4. Обновлять предлагай по одному шагу, самое опасное — первым; правки только после согласия.
