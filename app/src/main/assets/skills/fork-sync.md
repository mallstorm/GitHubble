---
name: fork-sync
description: Синхронизировать форк с исходным репозиторием
tools: github_request
---
1. repository_info: parent, ветки, насколько форк отстаёт (github_get /compare).
2. Если расхождений нет — POST /repos/{o}/{r}/merge-upstream с branch (быстрая перемотка).
3. Если есть собственные коммиты — предложи слияние в рабочую ветку и покажи возможные конфликты, основную ветку без согласия не трогай.
4. Сообщи итоговый коммит.
