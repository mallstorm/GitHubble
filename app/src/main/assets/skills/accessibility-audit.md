---
name: accessibility-audit
description: Проверить доступность интерфейса: контраст, подписи, размеры касания
---
1. Найди элементы без contentDescription/подписей, мелкие цели касания (< 48dp), слабый контраст.
2. Проверь порядок фокуса и поддержку крупного шрифта.
3. Для каждой находки — файл и конкретная правка.
4. Исправляй по согласию, начиная с самого заметного.
