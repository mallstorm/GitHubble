---
1. Прочитай существующий README и ключевые файлы (манифесты, точки входа, workflows) — пиши только то, что подтверждено файлами.
2. Структура: название и одно предложение о проекте, возможности, установка, использование с примерами команд, структура папок, разработка и сборка, лицензия.
3. Язык — как у текущего README или как просит пользователь. Не выдумывай команды и бейджи.
4. Покажи изменения как правку (replace_text/write_files) и опубликуй только после согласия.
