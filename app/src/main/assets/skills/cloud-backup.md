---
name: cloud-backup
description: Сделать резервную копию текстовых файлов репозитория или проекта в облако
---
1. Уточни, что копировать: весь репозиторий не получится, только выбранные файлы или важные папки (docs, конфиги, workflows, README).
2. Прочитай файлы через read_file/repository_read_file и собери архивную заметку: cloud_upload {source,path:"Backups/<repo>/<дата>/<имя>",content} для каждого файла (до 10 файлов за раз; больше — предложи группировать в один .md с разделами).
3. Секреты, токены, ключи подписи и .env не копируй никогда; keystore для релизов создаёт setup_release_signing, он остаётся в защищённом хранилище приложения.
4. В конце дай список выгруженного: путь в облаке, размер. Полный клон репозитория — это git clone или Mirror Manager, а не этот навык.
