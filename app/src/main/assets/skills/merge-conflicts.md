---
name: merge-conflicts
description: Разрешить конфликты слияния ветки
---
1. Определи ветки и конфликтующие файлы (pull_request_details, repository_files).
2. Для каждого файла прочитай обе версии и базу; пойми намерение обеих сторон.
3. Предложи объединённый вариант, не теряя ни одной из сторон; спорные места покажи пользователю (ask_user).
4. Внеси правки через ChangeSet, проверь сборку и тесты.
