---
name: billing-check
description: Проверить биллинг, минуты Actions, хранилище и пакеты аккаунта
---
1. github_usage — сводка плана и минут. Затем github_get:
   - /users/{login}/settings/billing/usage — использование по продуктам (если 404/403 — у токена нет доступа к биллингу; скажи об этом прямо);
   - /users/{login}/packages?package_type=container (также npm, maven, nuget) — пакеты и их размер;
   - /repos/{o}/{r}/actions/cache/usage — кэш репозитория.
2. Не выводи остаток лимита из названия плана. Если API не отдаёт цифру — так и скажи.
3. Итог таблицей: продукт, использовано, лимит (если известен), совет по экономии.
