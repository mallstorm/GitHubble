---
name: create-project
description: Создать новый проект: репозиторий, README, структура и CI-сборка
---
1. Уточни через ask_user: название, приватность (по умолчанию приватный), платформа и стек. Предложи рекомендуемый вариант.
2. create_repository (private:true, если не сказано иное) → привязать проект → write_files: README, .gitignore, минимальная структура.
3. CI: создай .github/workflows/*.yml под стек (сборка + тесты); запусти и дождись результата (dispatch_workflow, await_build).
4. Сообщи ссылку на репозиторий и результат первой сборки.
