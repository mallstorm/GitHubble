---
name: write-tests
description: Написать тесты для существующего кода
---
1. Определи фреймворк тестов проекта и стиль существующих тестов.
2. Выбери критичную логику без покрытия; начни с чистых функций и граничных случаев.
3. Пиши тесты по образцу проекта: понятные имена, одно утверждение на поведение, без обращения к сети.
4. Запусти тесты через CI и исправь падения; не меняй рабочий код без необходимости.
