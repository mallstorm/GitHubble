---
name: network-explainer
description: Объяснить сетевую или техническую тему по первоисточникам (TCP/IP, рукопожатия, Wi-Fi, DNS, TLS)
---
1. Найди первоисточник: RFC, стандарты IEEE, документацию вендоров. Примеры запросов: «TCP three-way handshake RFC 9293», «WPA2 4-way handshake IEEE 802.11i», «TLS 1.3 handshake RFC 8446». Используй web_research, при необходимости cloud_browser {url}.
2. Объясни по шагам: кто что отправляет, какие поля и состояния меняются, зачем нужен каждый шаг. Диаграмму сообщений нарисуй текстом (клиент → сервер).
3. Коротко по умолчанию (5–8 строк + схема), подробно — по просьбе: таймеры, ошибки, атаки, отличия версий.
4. Укажи номера RFC или разделов, на которые опираешься, и ссылки. Если источники расходятся — скажи.
5. Не давай инструкций по взлому чужих сетей; защита и понимание протоколов — можно.
