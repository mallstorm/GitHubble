# GitHubble — следующий проход 129–132

## 129. Сохранённые и закреплённые поиски
- сохранять область поиска, `RU ✦`, фильтры и исходный запрос как единый объект;
- закреплять избранные запросы;
- быстрый повтор из экрана поиска.

## 130. Управление вариантами и объяснимое ранжирование
- показывать созданные RU-варианты до повторного поиска;
- включать/отключать отдельный вариант;
- объяснять, почему результат поднят выше (совпадение нескольких вариантов, stars, смысловые токены и т. п.).

## 131. On-device UX/accessibility validation
- физический Android: клавиатура/IME;
- font scale 200%;
- TalkBack;
- портрет/ландшафт;
- MIUI/HyperOS;
- возврат после внешней страницы code search и GitHub auth.

Этот этап нельзя честно закрыть только в build-контейнере: нужен смартфон или эмулятор.

## 132. RC4 / кандидат 1.0 Stable
- исправить P0/P1 по on-device тестам;
- заморозить поисковую модель и строки;
- финальный APK/AAB/SBOM/mapping/checksums;
- подготовить 1.0 Stable при отсутствии блокирующих дефектов.
