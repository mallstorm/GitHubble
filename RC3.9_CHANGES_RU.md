# GitHubble RC3.9

База: RC3.8.1. В интерфейсе единственный вход — GitHub Device Flow; старый неиспользуемый PKCE/backend удалён. Подключение пользователя не может расширить права установленной GitHub App автоматически: для private-репозиториев владелец должен предоставить доступ в настройках установки GiHubble.

Исправлен misleading текст для нулевых и частичных списков репозиториев и принудительное обновление installation repository cache. Actions Billing за текущий месяц UTC: вместо неподтвержденного остатка — официальное использование, отдельно стандартные справочные лимиты; инвентаризация artifacts/cache не выдаётся за Billing. Ошибка API отображается, а не подменяется нулём. Подписанная release APK создаётся только при успешном GitHub Actions build.
