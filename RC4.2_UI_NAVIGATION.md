# GitHubble RC4.2 — интерфейс, навигация и отображение данных

Основа: RC4.1, commit `c066024b786e770d262b2c36829c334d487f6823`.
Текущая версия: `1.0.0-rc4.2`, versionCode `47`.

## Реализовано
- Единая нативная `BottomNavigationBar` выделена из `MainActivity`: Главная → Репозитории → Поиск → Активность → Профиль. Переход между корневыми вкладками очищает стек предыдущей вкладки; настройки доступны из профиля, а не дублируются пятой вкладкой.
- На главной выведен отдельный виджет реальных репозиториев из общего `RepositoryStore`, максимум пять. Быстрые ссылки-разделы остаются в отдельном блоке и не выдаются за список проектов.
- Экран репозиториев: фильтры по приватности и избранному, свёрнутые дополнительные языковые фильтры, сохраняемый режим «Список/Плитки» (две колонки на планшете, одна на телефоне), выдача карточек порциями по 24 без блокирования поиска на больших списках.
- Центр сборок: компактный заголовок и единая горизонтальная панель «Настроить/Обновить», фильтры «Все/В работе/Успех/Прочие», первые 12 запусков с дозагрузкой следующей порции. События и архивы остаются исходными данными GitHub Actions.
- При открытии репозитория устаревший сетевой результат больше не перерисовывает другой экран или экран другого аккаунта.
- Добавлены инструментальные тесты списка корневых вкладок и фильтрации статусов GitHub Actions; сохранены ранее созданные тесты безопасности Device Flow и RC4.1.

## Проверка на телефоне
1. Переключить пять корневых вкладок и открыть настройки из профиля (в том числе без входа).
2. Убедиться, что на главной показаны именно доступные проекты, а не декоративные плитки категорий.
3. На экране репозиториев проверить режимы, private/public, поиск, языковые фильтры, «Показать ещё» на большом списке, возврат назад.
4. В Центре сборок проверить фильтры и порционное отображение исторических запусков.
5. Быстро открыть репозиторий А → Б, сменить экран на медленной сети: карточки не смешиваются.
6. Проверить системный размер шрифта 100/150/200%, портрет/альбом и светлую/тёмную/бежевую темы.

## Не входит в RC4.2
Полный перенос всех экранов из большого `MainActivity`, полноценный редактор Git/PR review,
единый GitHub Inbox, backend для мгновенных push и серверный OAuth. Они остаются
отдельными этапами; Device Flow и подтверждённая вставка восьмизначного кода сохранены.
