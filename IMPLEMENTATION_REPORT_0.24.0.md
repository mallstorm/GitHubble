# GitHubble 0.24.0 — возврат после авторизации, профиль и Releases

## 1. Автоматический возврат после Device Flow

После получения состояния `AUTHORIZED` приложение теперь:

1. сохраняет токен через существующий защищённый механизм;
2. загружает профиль GitHub;
3. формирует Intent к существующей `MainActivity` с `CLEAR_TOP`, `SINGLE_TOP` и `REORDER_TO_FRONT`;
4. поднимает задачу GitHubble на передний план;
5. закрывает находящуюся сверху Chrome Custom Tab и показывает личный профиль.

Добавлен запасной маршрут через SharedPreferences: если конкретная прошивка Android не разрешит немедленное поднятие задачи, после ручного возврата приложение всё равно автоматически откроет профиль.

В Manifest добавлено обычное разрешение `android.permission.REORDER_TASKS`, а MainActivity работает в режиме `singleTop`.

## 2. Собственный профиль

Из личного профиля удалены две плитки:

- «Наблюдение»;
- «Следить за собой» / «Не следить за собой».

Механизм наблюдения за разработчиками сохранён в поиске, публичных профилях и разделе активности.

## 3. Страница Releases

Список assets переработан:

- каждый файл помещён в отдельную карточку с отступами;
- отображаются имя файла, размер, MIME-тип и количество загрузок;
- кнопка «Скачать» стала компактной и визуально отделена;
- длинные имена переносятся до трёх строк;
- исчез эффект слипшихся зелёных кнопок-«гармошки».

Загрузка по-прежнему выполняется через Android DownloadManager с системным прогрессом.
