# GitHubble RC4.2.4 — Native-first update

Version: 1.0.0-rc4.2.4, versionCode 51. Source baseline: e45981fa (RC4.2.3).

## Реализовано

- Вкладка «Активность» открывает нативный GitHub Inbox вместо перехода на github.com/notifications. Загружаются непрочитанные треды, доступны переходы к Issue/PR/репозиторию и запрос пометки выбранного треда прочитанным. Нужен доступ Notifications: Read.
- В Центре сборок карточка запуска открывает нативные детали Actions: состояние, ветку, SHA, задания, шаги и артефакты. ZIP скачиваются внутри приложения. Полный журнал GitHub остаётся дополнительным действием.
- Нативный commit diff отображает все строки patch, предоставленные GitHub API, порциями по 220 вместо локального обрезания после 550 строк. Бинарные и отсутствующие patch не могут быть восстановлены на клиенте.
- Встроенный редактор текстовых файлов (UTF-8, до 512 КБ) сохраняет правку отдельным Git-коммитом через Contents API и проверяет исходный blob SHA перед сохранением. Требуется Contents: Write и право изменять выбранную ветку.
- Контроллеры Actions и редактора вынесены из MainActivity в отдельные классы. Предыдущие возможности нативного PR review, комментариев к строкам и suggested changes сохранены.

## Ограничения и незавершённые работы

- Для настоящих мгновенных push необходимы Firebase project, сервер webhook, регистрация устройств и серверные секреты. Периодическая проверка JobScheduler остаётся единственным подключённым механизмом.
- Подписанный Release APK нельзя создавать без постоянного keystore/секретов GitHub Actions: при их отсутствии публикуются Debug APK и unsigned Release.
- GitHub Account Settings, billing, отдельные страницы Copilot и полные логи Actions открываются официальным браузером. Не все экраны и операции перенесены из MainActivity.
- PR split/unified diff остаются с отдельными лимитами UI; GitHub API может не вернуть текстовый patch для больших файлов. Полный Git-клиент и полный перенос всех экранов на отдельные модули не заявляются завершёнными.
- Перед публикацией production требуются ручные тесты на Android: private inbox с Notifications: Read, Actions с несколькими jobs, длинный patch, редактирование в защищённой ветке, конфликт SHA, офлайн/401/403 и смена аккаунта.
