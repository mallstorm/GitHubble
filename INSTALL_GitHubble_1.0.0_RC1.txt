GitHubble 1.0.0 RC1

versionCode: 28
versionName: 1.0.0-rc1-stage93-100
minSdk: 28
 targetSdk: 36

The APK uses the same signing certificate as GitHubble 0.25.0, 0.26.0 and 0.27.0. It can update those versions in place and preserve local data.

It cannot update versions signed by the older pre-0.25 certificate, including 0.24.0. Android will report a signature conflict in that case.

Recommended test order:
1. Back up portable settings from the installed version.
2. Install the RC APK as an update.
3. Verify that GitHub remains connected.
4. Open Settings → Release Candidate and Settings → Privacy and data.
5. Test one public repository before write operations.
6. Test offline queue and PR operations only in a disposable test repository.

The instrumentation APK is for adb/CI use and is not a standalone application.
