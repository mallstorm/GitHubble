Minimum Android: 9 / API 28

Обновление:
- устанавливается поверх основной GitHubble 0.25.0 или 0.26.0;
- сертификат release-линейки 0.25+ сохранён;
- удалять приложение не нужно;
- токен, профиль, избранное, наблюдение и настройки должны сохраниться.

Не устанавливается поверх 0.24.0 и более ранней ветки с другим сертификатом без предварительного удаления.

Рекомендуемая проверка:
1. Открыть Настройки → Данные → Офлайн-очередь.
2. Отключить сеть, изменить тестовую Issue, затем включить сеть и отправить очередь.
3. Изменить ту же Issue на сайте до повтора и проверить экран конфликта.
4. На тестовом репозитории открыть Управление и создать ветку/тег.
5. В Pull Request открыть Файлы и diff, переключить Unified/Split и добавить тестовый line comment.
6. Открыть PNG, SVG, PDF и бинарный файл.
7. Экспортировать резервную копию JSON и импортировать её обратно.

Операции записи сначала проверяйте на отдельном тестовом репозитории.
