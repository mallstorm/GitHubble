# GitHubble — отчёт реализации Stage 37–48

Версия: `0.20.0-alpha-main-stage37-48`  
Package: `app.githubble.mobile`  
minSdk: 28  
target/compileSdk: 36

## 37. Исправление «Активности»

Удалены запросы к `/notifications`, несовместимые с GitHub App user access token. Экран теперь объединяет поддерживаемые источники:

- назначенные и доступные Issues;
- открытые Pull Requests, связанные с пользователем;
- публичные события профиля.

События сортируются по времени. Счётчик новых элементов хранится локально. Добавлена кнопка перехода в официальный GitHub Notifications Inbox.

## 38. GitHub GraphQL transport

Добавлен `GitHubGraphQlClient`, использующий существующий авторизованный сетевой слой. Реализована обработка GraphQL `errors` и передача переменных.

## 39. GitHub Projects v2

Добавлена загрузка Projects v2 подключённого пользователя через GraphQL, отображение состояния, количества элементов, даты обновления и переход к проекту.

## 40. GitHub Discussions

Добавлены:

- Discussions подключённого пользователя;
- Discussions выбранного репозитория;
- экран темы;
- комментарии;
- отправка нового комментария через GraphQL mutation.

## 41. Полноценные Issues

Реализованы детальный экран, Markdown-тело, комментарии, создание Issue, редактирование title/body и реакции на Issue/комментарии.

## 42. Полноценные Pull Requests

Реализованы детали PR, ветки base/head, автор, состояние, mergeability, discussion comments и reviews.

## 43. Commits и changed files

Добавлены отдельные списки коммитов и изменённых файлов Pull Request.

## 44. Unified diff viewer

Добавлен нативный построчный просмотр patch с визуальным разделением добавленных, удалённых и служебных строк.

## 45. Расширенный Markdown

Поддержаны заголовки, списки, task lists, fenced code, inline code, жирный текст, таблицы, ссылки и изображения в безопасном текстовом представлении.

## 46. Защищённые настройки переводчика

Endpoint переводчика перенесён из обычных Preferences в Android Keystore-backed `SecureStore`. Добавлена миграция старого значения и очистка legacy-поля.

## 47. Системные загрузки

Release assets передаются в Android `DownloadManager`. Пользователь видит системное уведомление, прогресс и результат сохранения в Downloads.

## 48. Сборка и совместимость обновления

Release APK собран в офлайн Android SDK 36 / Gradle 9.5.1, выровнен и подписан прежним тестовым сертификатом GitHubble. Обновление устанавливается поверх версии 0.19.0 без удаления приложения.

## Что не изменялось

Запрошенная позднее перегенерация шестерёнки отменена пользователем. Иконка настроек в этом функциональном пакете намеренно не заменялась.
