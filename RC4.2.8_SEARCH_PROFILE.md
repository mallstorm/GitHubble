# RC4.2.8 · Верхняя панель, голосовой поиск, аватар

## Верхняя панель
Общая `MainActivity.shell()` не создаёт кнопки лупы и колокольчика при любом названии экрана и любом значении устаревшего аргумента `showSearchAction`. Поиск открывается нижней вкладкой, уведомления — через «Активность». Кнопка «Назад» и аватар вверху сохраняются.

## Поиск с микрофоном
В поле поиска нижней вкладки и в диалоге быстрого поиска справа находится микрофон. Один тап начинает запись после выдачи стандартного Android разрешения RECORD_AUDIO; второй тап останавливает запись, затем системная служба распознавания речи помещает готовый текст в редактируемое поле. Поиск запускает только пользователь после проверки текста и нажатия «Найти»; звук в приложении не хранится. Долгое нажатие микрофона — выбор ru-RU / en-US, по умолчанию язык телефона. На Android 14+ запрашивается автоматическое переключение между русским и английским, но его поддержка зависит от установленного распознавателя. На Android 13 и младше язык меняется вручную удержанием микрофона. Если служба распознавания отсутствует/недоступна, сохранён ручной ввод. Распознавание может обрабатываться системным провайдером через сеть согласно его настройкам; GitHubble самостоятельно не загружает аудио.

## Аватар
В нативном экране редактирования профиля добавлены «Загрузить свой аватар в GitHubble» (выбор изображения через системный документ-пикер, локальное хранение уменьшенной фотографии в частном хранилище конкретного аккаунта), «Убрать локальный аватар» и «Изменить фотографию аккаунта GitHub ↗». Кнопка замены GitHub-фотографии открывает официальный экран https://github.com/settings/profile: у документированного GitHub REST PATCH /user нет параметра для загрузки avatar. Локальный аватар меняет лишь отображение в GitHubble и НЕ меняет фотографию на github.com; при отсутствии локального изображения снова показывается GitHub avatar. Не выполняем недокументированную передачу учетных cookie/загрузку изображения на сторонние хосты.

## Приемка
PR Android checks: Gradle test + assembleDebug + assembleRelease. После merge в main — итоговая сборка и публикация GitHub prerelease. Нужно вручную проверить Android 13: запрос разрешения, красный STOP, результат в поле, переключение ru-RU/en-US, загрузку JPEG/PNG и смену локального аватара, отсутствие верхних кнопок на вложенных экранах, а также решение Play Protect для APK. CI не заменяет проверку микрофона и установки на реальном устройстве.
