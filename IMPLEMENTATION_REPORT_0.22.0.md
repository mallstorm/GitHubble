# GitHubble 0.22.0 — вставка полного Device Flow кода

## Исправлено

GitHub выдаёт пользовательский код Device Flow в формате `XXXX-XXXX`, а страница `github.com/login/device` использует восемь раздельных полей. Некоторые Android-браузеры и клавиатуры при вставке строки с дефисом помещали только первый символ.

Реализация 0.22.0:

- перед копированием удаляет дефис и любые разделители;
- помещает в буфер ровно 8 буквенно-цифровых символов в верхнем регистре;
- повторно копирует код непосредственно перед открытием GitHub;
- добавляет кнопку «Скопировать код»;
- позволяет повторно скопировать код нажатием по крупному коду;
- показывает пользователю точное значение, находящееся в буфере;
- на Android 13+ помечает содержимое буфера как конфиденциальное;
- не использует WebView, Accessibility или внедрение JavaScript в страницу GitHub.

## Ограничение GitHub

Официальный Device Flow GitHub возвращает `verification_uri`, но не возвращает `verification_uri_complete`, поэтому приложение не может официально передать код в URL и заполнить сайт без участия пользователя. Исправление обеспечивает корректную вставку всех восьми символов одним действием в первое поле.
