# UI design system

Принципы: плоские карточки с тонкой рамкой (без `elevation`), компактные отступы, один набор радиусов.

- **Радиусы** — `ui/DesignSystem.radius(dp)`: малые метки (≤8) сохраняются, контролы и бейджи 10, карточки 12, пилюли/круги (≥24) сохраняются. `MainActivity.round()` и локальные хелперы экранов применяют шкалу автоматически.
- **Зазоры** — не меньше 6 dp между соседними кнопками, чипами и плитками. `UiPolish` проверяет это при каждой раскладке (LinearLayout и GridLayout) и убирает тень у `Button`.
- **Текст** — `text()` с эллипсисом и отступом 4×2 dp; JSON `null` читается через `ui/JsonText`.
- **Плитки** — трёхколоночные вертикальные (`repoActionCard` при ≥3 колонок), двухколоночные горизонтальные строки.
- **Проверка** — `FlatDesignGuardTest` запрещает `setElevation`; workflow «Redesign UI review» рендерит реальные экраны с синтетическими данными и пишет `audit.txt` (TOUCHING / STACKED-TIGHT / TEXT CLIPPED / OVERFLOW); рендеры публикуются в ветку `preview/redesign-ui`.
