# Agent Supervisor

`Supervisor` сверяет утверждения агента с независимыми свидетельствами (`Evidence`):
ветка и коммит существуют, PR существует, запуск workflow относится к нужному sha и завершён успешно,
артефакт существует. Результат — список находок и вердикты PASS/FAIL/UNVERIFIED.
Реализация `Evidence` для GitHub — `GitHubEvidence` (404 трактуется как «не найдено»).

Ограничение: проверка содержимого APK в `verify_build` не выполняется (`apk_inspected=false`), потому что
APK не скачивается в этом инструменте. `ArtifactVerifier` умеет проверять APK (пакет, versionCode,
versionName), но не встроен в загрузчик. Это записано, а не скрыто.
