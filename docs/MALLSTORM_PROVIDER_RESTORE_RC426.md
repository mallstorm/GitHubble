# GitHubble rc4.2.26 — нативные подключения и инструменты

Исходный эталон: **mallstorm/OmniChat**, коммит `e4b3b5be20d757c16eb2675dd49f05433bb8d000` (1.0.11). Digger401 не использовался как основа этого переноса. Перенесены ApiGateway, ChatGptPlanClient, Grok OAuth/Imagine, вспомогательные протоколы, реестр провайдеров, HTTP MCP. Сохранена оболочка GitHubble.

## Подключения

| Раздел | Реализация | Границы |
|---|---|---|
| API | Реестр OmniChat; OpenAI Chat/Responses, Anthropic, Gemini, Ollama, GigaChat OAuth, Yandex, OpenAI-совместимые сервисы; свой endpoint, протокол и scope | Наличие шаблона не подтверждает оплату, доступ к модели или исправность внешнего сервера |
| ChatGPT | Прямой OAuth, динамический агентный клиент, PKCE/state/nonce/JWKS, `chatgpt.tokens.use.direct`, `api.openai.com/v1/responses` | Требуется разрешение OpenAI для аккаунта; Codex CLI не запускается и не используется как запасной транспорт |
| Gemini | Google Cloud Code/Antigravity OAuth, проект, обновление токена, серверный fetchAvailableModels | Удалён локальный фильтр семейств; права и лимиты Google сохраняются |
| Grok | OAuth device flow, обновление токена, серверный каталог, Responses и Imagine | Модель Grok 4.7 появляется, если её возвращает сервер аккаунту; фиктивный идентификатор не добавляется |
| Claude | Нативный OAuth, Anthropic Messages | Генерация изображений не объявляется поддерживаемой |
| Cline / Kimi | Сохранены существующие нативные подключения и каталог Cline Free/Pass/Billing | Внешняя авторизация обязательна |
| OpenRouter / Kilo | Отдельные аккаунтные OAuth-подключения: PKCE loopback / device flow; выдаваемые провайдерами ключи хранятся зашифрованно | Не заменяют ручной API-профиль |
| Subscription Proxy | Независимые ChatGPT/Gemini/Claude/Grok профили; внешний CLIProxyAPI; NVIDIA NIM | Нет совместного хранилища с основными подписками; внешний proxy должен быть доступен с телефона |

Секреты изолированы по GitHub-профилю, подписке и типу подключения. Обновление сессий защищено от восстановления после отключения и гонок refresh. Каталог загружается до выбора модели; пустой каталог не подменяется придуманным списком.

## Меню «Добавить»

| Действие | Исполнение |
|---|---|
| Камера | Системная камера, FileProvider, приватный файл, подтверждение вложения |
| Фото / анализ / вопрос | Системный выбор, Vision выбранного провайдера; фото уходит после отправки сообщения |
| OCR | Камера или галерея; запрос распознавания с сохранением структуры |
| Файлы | Существующий импорт файлов в Workspace и текстового контекста |
| Создание изображения | Реальные OpenAI Responses/image API, Gemini native/Cloud Code, Grok Imagine, OpenRouter, Yandex и совместимые API; результат сохраняется в истории, предпросмотр и экспорт |
| Веб-поиск | Реальный поиск RSS/HTML, ссылки на источники, частичные ошибки; включается пользователем |
| Плагины | HTTPS GET/POST и Streamable HTTP MCP; собственный зашифрованный Bearer, обнаружение инструментов, включение/удаление, подтверждение каждого вызова |

Медиа сохраняются с метаданными и переживают перенос истории в SQLite (схема 3, аддитивное обновление). Сгенерированные изображения не отправляются модели повторно автоматически. Изображения ограничены по размеру и числу пикселей. Камера и незавершённые действия сохраняют привязку к аккаунту и диалогу при пересоздании Activity.

## Агент и планирование

Основной режим всегда агентный: обычные рассуждения проходят без вызова инструментов. Планирование отключает запись файлов, GitHub-изменения, генерацию изображений и сторонние плагины. Чтение и поиск остаются доступны. Разрешения отдельно регулируют просмотр, подтверждение, локальную автоматику и GitHub-автоматику. Для сторонних расширений подтверждение обязательно. События файлов показывают путь, создание/карандаш, зелёный плюс и красный минус строк.

## Проверка

Автотесты проверяют прямой ChatGPT models-запрос на локальном HTTP fixture, оба формата каталога, отсутствие семейного ограничения Gemini, выбор протоколов и алиасы proxy. Android 13 instrumentation проверяет интерфейс, клавиатуру, изоляцию OAuth-профилей, архив событий/медиа, запрет небезопасного URL плагина, изоляцию и отсутствие секретов в каталоге инструментов. Сборка выполняет unit tests, Debug и Release, проверяет ARM64 состав и Android 13 UI.

**Реальные входы в личные аккаунты провайдеров не выполнялись.** Успешная сборка и fixture-тесты не подтверждают действительность внешнего OAuth-клиента, подписку или баланс пользователя. При отказе серверов приложение показывает ошибку; обходов прав и скрытого перехода на Codex/Gemini Web нет.

Документация image tool: https://developers.openai.com/api/docs/guides/tools-image-generation и https://developers.openai.com/api/docs/guides/image-generation. Имена моделей выбираются из серверного каталога либо явно задаются пользователем.
