# Автоматический протокол Hubble Agent

Для прямых API-подключений с OpenAI-совместимым форматом агент проверяет Responses API, затем Chat Completions. Настройка протокола и каталог моделей сами по себе не доказывают поддержку инструментов. Немотрон и другие модели не объявляются неработоспособными из-за одного отказа маршрута Responses.

## Что проверяется

До пользовательских операций выполняется безопасная проба `hubble_capability_probe`: поток SSE должен завершиться, вернуть нативный вызов функции с уникальным аргументом, а затем правильно обработать результат инструмента. Проба не получает файлы, репозитории или пользовательскую переписку. Принудительно выставляемых флагов capabilities нет. Первый выбор протокола требует дополнительных коротких запросов к выбранному API; общий тайм-аут одной пробы — 60 секунд.

Отказы маршрута/формата HTTP 400/404/405/415/422/501 и неподтверждённый streaming/tool calling допускают переход к следующему протоколу. Ошибки ключа, доступа, квоты, сети, отмена и сбои сервера не считаются доказательством отсутствия возможностей и не запускают такой переход. Требуются `text/event-stream`, завершённый ответ и корректные JSON-аргументы. Обычный текст, неоконченный поток или JSON вместо запрошенного SSE не подтверждают возможности агента.

Положительная проверка хранится только в памяти, до 30 минут. Идентификатор учитывает аккаунт, провайдера, адрес, модель, исходный протокол, auth scope и SHA-256 отпечаток ключа. Сырые ключи в кеш не попадают. После перезапуска приложения проверка выполняется заново. Настройки подключения не переписываются.

## Выполнение

Рабочие запросы используют нативную функцию `hubble_action {name,args}`. Доступные операции перечисляются текущим хостом на каждом шаге. `ProjectRuntime` сохраняет проверки аккаунта, разрешений, подтверждения изменений, лимиты и защиту от повторов. Результаты возвращаются с исходным `tool_call_id` / `call_id`. Текстовый JSON не может подменить нативный вызов. Уже начатые рабочие запросы не повторяются через другой протокол, чтобы не дублировать изменения.

OAuth-подписки и специализированные транспорты Anthropic, Gemini, GigaChat, Cohere, Cloudflare и Yandex продолжают пользоваться своими адаптерами. Автоподбор OpenAI-протокола к ним не применяется.

## Интерфейс

В выборе модели заголовок, поиск и фильтры остаются на месте. Прокручивается отдельный каталог с плитками подключения и моделями; высота плиток зависит от текста. Окно учитывает доступные границы и системные панели, клавиатура уменьшает каталог. Автопрокрутка чата больше не переносит фокус через `fullScroll`.

## Проверка

Локальные HTTP-фикстуры проверяют fallback, оба SSE-формата, нативные инструменты и результат, истечение кеша, изоляцию ключей/аккаунтов, ошибки HTTP и отмену. Android-проверка открывает настоящий выбор модели, меняет поиск/фильтры, прокручивает каталог и включает клавиатуру: три темы, масштабы приложения 80/110%, шрифты 100/150%.

Запросы к настоящему KeyDealer с пользовательским ключом не выполнялись. Поддержку конкретной модели на конкретном аккаунте подтверждает проба при её использовании в приложении.
