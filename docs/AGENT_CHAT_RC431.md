# Агентский чат RC4.2.31

Реализация согласованного предложения из записи 08.11.2026 и исходников Digger401/OmniChat 407cc6722f52f2e360b8e4449e48d98f2989e509. Основа GitHubble — 44e7f9f. Версия 1.0.0-rc4.2.31, код 78.

## Реализация

- AgentRun и ProjectRuntime.Listener описывают реальные границы итераций и инструментов. Модель не может прислать текст и объявить им инструмент выполненным.
- AgentRunBinding объединяет UI-обновления и сохраняет снимки вне главного потока. AgentRunRegistry отличает живой процесс от сохранённого флага работы; AgentUiSession держит исполнителя при смене конфигурации, а подтверждения привязаны к текущей Activity.
- Новая строка работы содержит пиктограмму, действие, цель, состояние и длительность. Чтения сворачиваются в группу. Таймер — монотонный, с табличными цифрами; обновляет только видимую строку.
- AgentChatScreen обновляет историю, сохраняя composer и позицию прокрутки. Поддерживаются старые системные записи без выдумывания отсутствующих путей и времени.
- В поле ввода нет переключателя «План». Старое сохранённое значение режима не влияет на работу. READ_ONLY/REVIEW/LOCAL_AUTO/GITHUB_AUTO продолжают контролировать разрешения.
- CommonMark 0.24.0 и GFM extensions разбирают структуру Markdown. Нативный renderer не интерпретирует HTML, не исполняет JavaScript и не загружает картинки автоматически. Код сохраняется при копировании; длинные таблицы подгружают строки частями.
- Отдельный документ показывает форматированный текст либо исходник; экспорт .md использует системный file picker и проверку аккаунта/диалога.
- AgentDiffStore хранит bounded-снимки до/после в приватном каталоге с проверкой account/thread и непрозрачными ID. Счётчики берутся из существующего FileChangeStats; приблизительные значения помечены.
- После отправки удалённой записи отмена или неопределённая ошибка не изображается доказанным отсутствием изменений. UI показывает неизвестный результат; автоматическое продолжение такого исполнения прекращается.
- GitHubAgentBridge захватывает сессию под общим SecureStore.SESSION_LOCK и использует bound session. Это важно для задач, переживших пересоздание Activity.
- NativeProviderRuntime передаёт реальные preview-обновления. Прямой Chat Completions/Responses маршрут разбирает SSE и usage; текстовые JSON-конверты инструментов скрыты. Для нестриминговых ответов выводится фактический результат без искусственной печати.
- История сохраняет до 80 000 символов ответа, без прежнего молчаливого обрезания до 6000. Общий объём быстрого transcript ограничен; вытесненные записи остаются в SQLite archive. Схема archive 4 добавляет run без удаления данных.

## Проверки

Новые unit-тесты покрывают таймер, ожидание подтверждения, поздние результаты после отмены, неизвестную удалённую запись, независимость снимков, SSE/usage, скрытие tool JSON и reasoning, Markdown AST, вложенные задачи, безопасные схемы ссылок, diff и порядок событий runtime.

Android workflow Agent chat UI использует неэкспортируемую debug-only Activity на чистом устройстве без GitHub-токена. Renderer и оболочка production, данные синтетические. Проверяются локальный цикл create_workspace → write_files с фактическими 150 строками, snapshot diff, миграция архива с версии 3, длинный ответ, архивирование run, таймер, Activity recreation, отмена, сохранение composer, документы, diff и IME. 36 снимков: 3 темы × 2 масштаба шрифта × 6 состояний.

Снимки публикуются в изолированную ветку preview/agent-ui-<SHA>, без изменения исходной ветки и без зависимости от квоты Actions artifacts. Preview Activity отсутствует в Release.

Окончательные CI-результаты, просмотр снимков и проверка подписи APK фиксируются отдельно. Добавление тестов не означает их успешного выполнения. Авторизованные изменения в реальных пользовательских GitHub-аккаунтах и внешние AI-провайдеры тестовым прогоном не вызываются.
