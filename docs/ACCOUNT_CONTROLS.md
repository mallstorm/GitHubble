# Первый пакет расширения аккаунта

Ветка feat/account-controls от RC4.2.28. Версия релиза пока не меняется; production APK из PR не публикуется.

Настройки → Аккаунт и GitHub → Управление аккаунтом и доступом:

- список согласованных прав установок с догрузкой страниц;
- переход к согласованию прав и повторной пользовательской авторизации;
- постраничный список блокировок, Block/Unblock с подтверждением;
- просмотр, установка и удаление interaction limits, выбор режима и срока;
- восстановление экранов после пересоздания Activity.

Все запросы новых функций используют сессию, закреплённую до старта асинхронной работы. Смена аккаунта отменяет устаревший контекст, результат не попадает на новый экран. Записи используют существующую семантику UNKNOWN и не повторяются автоматически при неизвестном результате.

Стабилизация: Issue/PR закрепляют HTTP-контекст и проверяют поколение/аккаунт/целевой View перед отрисовкой; неизвестное admin не считается true; доступная установка организации принимается при подключении. Inbox явно использует официальный сайт вместо заведомо несовместимого Notifications API.

Контрактные тесты проверяют маршруты/методы, допустимые параметры, отмену по смене сессии и пагинацию установок. Реальные Block/Unblock и установка interaction limits не выполняются CI на пользовательском аккаунте. Перед выпуском нужна приёмка на устройстве с подтверждёнными правами.

Проверка публичной регистрации GiHubble при разработке: blocking и interaction_limits имеют write, followers по-прежнему read. Сведения о регистрации не доказывают, что конкретный пользователь уже согласовал новые права.
