# Панель активности и уведомления

**Панель запуска** (`AgentRunView`) в диалоге показывает итерации, инструменты, статусы, ошибки и, если у запуска есть журнал,
строку «Состояние: <этап> · режим: <авто|полуавто|ручной>» (`task_state`/`mode` из `AgentRun.snapshot()`).

**Продолжить с контекстом.** Для последнего запуска диалога, если он прерван, завершился ошибкой либо приостановлен
(PAUSED/FAILED/WAITING_EXTERNAL), показывается кнопка. Она отправляет агенту сообщение с кратким протоколом прошлого запуска
(до 12 последних операций: имя, цель, статус, ошибка без секретов). Правила в сообщении: не повторять успешные записи, неизвестные
исходы сначала проверять в GitHub, при PAUSED — проверить статус сборки. Это **новый запуск** с контекстом, а не восстановление
цикла модели. Протокол помечен как справочные данные, не инструкции.

**Уведомления** (`AgentNotifier`, канал «Задачи агента»): «нужно подтверждение» и «задача завершена/остановлена/ошибка/прервана».
Показываются только когда UI не на переднем плане (`AgentUiSession.foreground`, по onResume/onPause) и при выданном разрешении
POST_NOTIFICATIONS. В тексте нет аргументов инструментов. Ограничение: после закрытия процесса уведомлений нет (нет фонового
исполнителя).

Не реализовано: отдельный экран всех задач, фильтры, уведомления о результате сборки при закрытом приложении (есть прежний
`BuildMonitor` для коммитов и запусков).
