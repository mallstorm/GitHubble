## Сценарии ТЗ §17.3 — честный статус
| Сценарий | Статус |
|---|---|
| A — новый проект | НЕ ВЫПОЛНЕНО: нужны живой GitHub и модель |
| B — исправление ошибки сборки | НЕ ВЫПОЛНЕНО вживую; компоненты (классификатор, RetryPolicy, repair-диалог, `await_build`) покрыты юнит-тестами |
| C — существующий проект, PR | НЕ ВЫПОЛНЕНО вживую |
| D — восстановление после закрытия | СИМУЛЯЦИЯ логики журнала (`ScenarioSimulationTest`); на устройстве не проверялось. Цикл модели не возобновляется (есть «Продолжить с контекстом») |
| E — AUTO → MANUAL | СИМУЛЯЦИЯ: уровень разрешений читается при каждом вызове, режим MANUAL требует подтверждения; живой прогон не выполнялся |
| F — отказ по правам | СИМУЛЯЦИЯ классификации и решения политики; живой 403 не воспроизводился |
| G — зелёный workflow без APK | СИМУЛЯЦИЯ через `Supervisor`; живой прогон не выполнялся |
| H — смена аккаунта | Покрыто существующими тестами привязки сессии (`GitHubSession`, `bindCurrentSession`), живой сценарий не выполнялся |
