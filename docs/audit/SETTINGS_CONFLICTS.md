# Аудит настроек и конфликтов

Метод (проход C): статическое сопоставление строковых ключей `SharedPreferences` (чтение/запись) по всем исходникам плюс ручная
проверка каждого подозрительного ключа. Интерактивный обход экранов на устройстве **не выполнялся**; динамические ключи
(`"ai_tool_github_read_"+аккаунт` и т.п.) учитываются по префиксу. Сканер даёт ложные срабатывания на JSON-поля, поэтому
перечислены только проверенные вручную находки.

## Рабочие и согласованные
| Настройка | Где применяется | Статус |
|---|---|---|
| Уровень разрешений агента (4 уровня) | `AgentPermissionPolicy`, `NativeAgentToolHost`; режимы AUTO/SEMI/MANUAL выводятся из уровня | WORKING |
| Доступ агента к GitHub / файлам (`ai_tool_github_read_<аккаунт>`, `ai_tool_file_read_<аккаунт>`) | `MainActivity.agentSend`, `scopeGuard` на каждом шаге | WORKING |
| Уведомления сборок (`build_notifications`) | `BuildMonitor`, `BuildAdaptiveScheduler` | WORKING |
| Пороги трекинга: звёзды, forks | меняются в диалоге, читает `TrackingEngine`, входят в портативный бэкап | WORKING |
| Провайдер перевода | сохраняется диалогом, читается `TranslationController`, входит в бэкап | WORKING |

## Находки
| Ключ | Проблема | Статус |
|---|---|---|
| `tracking_max_pages`, `tracking_release_check_limit` | **Исправлено**: строки в настройках отслеживания теперь открывают диалог ввода (1–10 страниц по 100; 1–30 репозиториев для проверки релизов); движок читает те же ключи с ограничением диапазона. Проверяется CI, вручную не проверялось |
| `translator_chunk_size` | Читается `TranslationController`, в UI не задаётся | PARTIAL (только значение по умолчанию) |
| `last_download_id`, `last_download_name` | Пишутся при загрузке, нигде не читаются | UNUSED (безвредная запись) |
| `tracking_job_last_finished` | Пишется `TrackingJobService`, нигде не читается | UNUSED (диагностическая запись) |
| `search_enabled`, `browser_enabled` (файл `web_access`) | Читаются `WorkspaceTools` с запасным ключом `enabled`; запись по литералам не найдена | UNKNOWN: возможно устаревшие ключи, нужен обход UI |

## Разрешённые конфликты
- Два хранилища AI-подключений (`AiConnectionStore` и `OmniChatConnectionStore`): неиспользуемое `AiConnectionStore` удалено в проходе C, активное — `OmniChatConnectionStore`.
- Дублирование каталога возможностей хоста в промпте — исправлено в проходе A.

## Остаются
- Настройки-призраки из таблицы выше; UNKNOWN-ключи `web_access`.
- Не проверено: совпадение текста настроек с фактическим поведением на устройстве, конфликты между экранами настроек, которые видны только при работе с UI.
