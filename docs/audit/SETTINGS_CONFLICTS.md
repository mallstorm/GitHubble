# Аудит настроек и конфликтов

Проверялось статически (чтением кода); интерактивный обход экрана настроек не выполнялся.

| Настройка | Где хранится | Применяется | Замечание |
|---|---|---|---|
| Уровень разрешений агента (4 уровня) | `AgentPermissionPolicy` / настройки диалога | Хостом при каждом вызове | WORKING. Режимы AUTO/SEMI/MANUAL (`ExecutionMode`) отображаются на эти уровни методом `permissionLevel()`, но выбора режима в UI пока нет |
| Раскрытие данных модели (согласия) | Настройки аккаунта | `NativeAgentToolHost` | WORKING |
| Провайдер/ключ AI | `AiConnectionStore` (UNUSED) и активные хранилища провайдеров | Активный путь — не `AiConnectionStore` | CONFLICT: два хранилища, одно мёртвое; удалять только после проверки миграций |
| Авто-загрузка сборки | `BuildAutoDownloadPolicy` | Политика есть; связь с проверкой APK отсутствует | PARTIAL |
| Лимиты агента (раунды/инструменты) | Константы `ProjectRuntime` | Жёстко | Не настраиваются пользователем (по ТЗ допустимо) |
| Лимиты сборок/автоисправлений | `RetryPolicy.Limits` (8 сборок, 5 исправлений, 3 временных повтора) | Хостом на диалог | Не настраиваются в UI |

хоста в промпте (D5). Прочие настройки — UNKNOWN до интерактивного обхода.
