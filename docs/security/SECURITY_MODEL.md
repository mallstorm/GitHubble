# Модель безопасности

- Секреты: Android Keystore (AES-GCM) через `SecureStore`; не пишутся в журналы и память проекта.
- Аккаунт: операции агента привязаны к активной сессии под `SESSION_LOCK`; смена аккаунта прерывает операцию (D1 исправлен в Git-workspace, диагностике и загрузке артефактов).
- Модель не получает произвольных URL/методов — только каталог инструментов; аргументы валидируются хостом.
- Опасные действия всегда требуют отдельного подтверждения (`ExecutionMode.DANGEROUS`; в боевом пути — уровни разрешений и ревью).
- Бюджет сборок и автоисправлений ограничен хостом; сбои биллинга/прав/подписи не «обходятся».
- Не проверено: внешний пентест, статический анализ уязвимостей, поведение на реальных устройствах.
