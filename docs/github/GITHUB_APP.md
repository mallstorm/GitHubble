# GitHub App

**Статус: частично.** Приложение читает установки и права (`github_capabilities`). Действия агента от имени
установки GitHub App (отдельная идентичность коммитов, installation token) **не реализованы** — для этого нужен
сервер, хранящий приватный ключ App; в мобильном клиенте ключ хранить нельзя.
