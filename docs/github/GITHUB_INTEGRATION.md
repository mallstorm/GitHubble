# Интеграция с GitHub

Клиент `GitHubApiClient` привязывается к сессии (`bindCurrentSession`, `SESSION_LOCK`) — при смене аккаунта
операции отклоняются. Инструменты агента — см. `docs/agent/TOOL_CONTRACTS.md`. Авторство коммитов и PR —
пользователь (его токен). Токены не попадают в журналы (редактирование секретов).
Релизы: `list_releases`, `create_release` (черновик по умолчанию, без загрузки файлов). `dispatch_workflow` проверяет workflow и
триггер заранее и возвращает run_id. Ограничения: загрузка файлов в релиз и публикация/удаление релизов не реализованы;
определение запуска опирается на список запусков GitHub и при параллельных dispatch бывает неоднозначным (помечается).
