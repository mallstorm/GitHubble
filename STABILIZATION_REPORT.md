# GitHubble 0.13.0 — стабилизационный проход

Реализованы: очистка ключей, SecureStore, PKCE/OAuth backend exchange, централизованный GitHubApiClient, типизированная модель RepositorySummary, удаление демонстрационных персональных данных, расширение строковых ресурсов и подготовка навигационного состояния.

Ограничение: полная миграция всех 748 строк UI из MainActivity в отдельные feature-модули требует следующего прохода; текущий APK сохраняет визуальную совместимость и уже использует вынесенные security/network/auth слои.
