# Политика конфиденциальности GitHubble

GitHubble — клиент GitHub. Приложение не получает пароль GitHub: вход и регистрация выполняются на официальных страницах GitHub через Android Custom Tabs.

OAuth-токен хранится на устройстве в зашифрованном виде через Android Keystore. Профили, репозитории, переводы, избранное, история наблюдения и офлайн-очередь сохраняются локально для работы приложения. Данные передаются только GitHub и выбранному пользователем сервису перевода. Ключ переводчика хранится через Android Keystore.

Пользователь может открыть «Настройки → Конфиденциальность и данные», экспортировать безопасную копию своих локальных данных либо полностью удалить токен, кэш, историю, настройки и очереди. Удаление локальных данных не удаляет аккаунт или содержимое на GitHub.

В экспорт не включаются OAuth-токен, пароль, API-ключ переводчика и ключ подписи приложения.
