# GitHubble RC4.2 — интерфейс и навигация

- Версия 1.0.0-rc4.2, versionCode 47.
- Пять единых корневых вкладок: Главная, Репозитории, Поиск, Активность, Профиль. Настройки доступны из профиля.
- На главной отображаются до пяти реальных репозиториев аккаунта, независимо от декоративных быстрых ссылок.
- Репозитории: список/плитки, сворачиваемые языковые фильтры, порционная отрисовка по 24 карточки.
- Центр сборок: компактные действия, фильтры по статусу и порционная история запусков.
- Поздние ответы загрузки отдельного репозитория не рисуются поверх другого экрана/аккаунта.
- Device Flow, полная вставка восьмизначного кода и отсутствие нижней браузерной полоски сохранены.

## Ограничения

- Для UI-изменений требуется приёмка на Android/MIUI; успешный CI не подтверждает удобство конкретного устройства.
- Подписанный Release APK создаётся только при наличии постоянного ключа в GitHub Secrets.

# GitHubble RC4.1 — стабилизация

- Версия 1.0.0-rc4.1, versionCode 46. Основная ветка: main.
- Один автоматический запуск CI после пакетного коммита в main: push в рабочие/резервные ветки не создаёт промежуточных Android-сборок; устаревший запуск той же ветки отменяется.
- Центр сборок группирует новые уведомления по репозиторию: не больше одного за проверку и одно место в шторке.
- Billing загружается независимо от инвентаризации Actions. Хранилище проверяется отдельным действием с ходом, отменой и явной отметкой частичного результата.
- При переходе на другой экран либо смене аккаунта устаревшие данные сканирования не вставляются в текущий интерфейс.
- Device Flow и копирование восьмизначного кода сохранены; дополнительная нижняя панель браузера удалена.

## Ограничения

- На устройстве владельца предстоит проверить длительное сканирование при 100+ репозиториях и работу JobScheduler на MIUI.
- Подписанный Release APK создаётся только при настроенном постоянном ключе подписи.

# GitHubble 1.0.0 RC4.0 — модернизация и стабилизация

- единый `RepositoryStore`: Home и «Мои репозитории» используют один snapshot;
- пагинация более 100 репозиториев, stale-while-revalidate и явное состояние ошибки;
- HTTP/ETag cache изолирован по аккаунту, 304 без тела больше не маскируется;
- OAuth сохраняет expiry/refresh metadata, поддерживает безопасную ротацию и reauth после 401;
- офлайн-очередь привязана к аккаунту, repository и idempotency key, имеет TTL;
- logout очищает приватный кэш и очередь текущего аккаунта;
- устаревший force reset HEAD удалён из навигации; default branch защищена;
- очистка Actions инвалидирует каждый затронутый репозиторий;
- неизвестное состояние star/follow не показывается как `false`;
- bottom navigation: Главная, Репозитории, Поиск, Активность, Профиль;
- исправлены accessibility touch targets и семантика без принудительного focus order;
- диагностический экспорт использует whitelist и не выгружает приватные payload;
- версия вынесена в `version.properties`, UI/User-Agent/artifacts читают BuildConfig;
- CI выполняет tests, lint, debug/release build и emulator regression suite;
- release без постоянного signing keystore блокируется.
