# GitHubble

Русскоязычный Android-клиент GitHub для просмотра репозиториев, профилей разработчиков, Issues, Pull Requests, Discussions, Projects и Releases.

## Основные возможности
- официальный вход GitHub через GiHubble;
- перевод README, Issues, PR, Discussions и Releases с защитой кода;
- отслеживание новых репозиториев и релизов разработчиков;
- просмотр исходного кода и unified/split diff;
- работа с Issues и Pull Requests;
- офлайн-кэш и очередь изменений;
- светлая, бежевая и графитовая темы;
- экспорт и удаление локальных данных.

GitHubble не запрашивает и не хранит пароль GitHub.
