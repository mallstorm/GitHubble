# Copilot RC2 — проверка на устройстве

1. Установить RC2 поверх RC1.4 и убедиться, что аккаунт и настройки сохранены.
2. Открыть репозиторий → Copilot → Матрица разрешений.
3. Подтвердить Agent tasks: Read and write в настройках GiHubble.
4. Запустить безопасную тестовую задачу в отдельном тестовом репозитории.
5. Проверить смену queued → in_progress → completed/waiting_for_user.
6. Проверить автообновление 15/30/60/120 секунд.
7. Включить фоновый мониторинг, разрешить уведомления, свернуть приложение.
8. Проверить переход по уведомлению прямо к задаче.
9. Проверить список `.github/agents/*.agent.md` и запуск с выбранным профилем.
10. Проверить активные, завершённые и архивные задачи.
11. Проверить MIUI/HyperOS: автозапуск, батарея без ограничений и уведомления.
12. Зафиксировать HTTP-коды, тело ошибки и скриншоты для любого P0/P1 дефекта.
