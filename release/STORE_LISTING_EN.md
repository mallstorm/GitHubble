# GitHubble

An Android GitHub client focused on Russian-language reading, repository discovery, developer tracking, Issues, Pull Requests, Discussions, Projects and Releases.

## Highlights
- official GitHub authorization through GiHubble;
- protected translation of Markdown while keeping code and links intact;
- tracking of new repositories and releases;
- source viewer and unified/split diff;
- offline cache and replay-safe action queue;
- light, beige and graphite themes;
- local data export and deletion controls.

GitHubble never asks for or stores your GitHub password.
