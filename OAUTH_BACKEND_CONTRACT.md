# Устаревший backend-контракт

Этот документ сохранён только для истории ранней архитектуры.

Активная Android-сборка GitHubble 0.19.0 использует GitHub Device Flow и не выполняет обмен authorization code через собственный backend. Client Secret внутри APK отсутствует.

Отдельный сервер может понадобиться позднее только для функций, которые действительно требуют серверного доверенного компонента. Он не должен журналировать или постоянно хранить пользовательские токены без явной необходимости.
