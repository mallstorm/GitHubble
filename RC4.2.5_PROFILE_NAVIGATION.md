# RC4.2.5 — нижние настройки и нативный редактор профиля

- Пятая корневая вкладка теперь «Настройки» с шестерёнкой; «Профиль» открывается по аватару справа в верхней панели, из «Настройки → Аккаунт и доступ → Личный профиль» или после входа в GitHub.
- Убраны верхняя шестерёнка на странице профиля и большая повторяющаяся карточка «Настройки приложения». Основная плашка с аватаром и карандашом начинается сразу под заголовком; отступы карточки и статистики уменьшены.
- Карандаш открывает нативную страницу редактирования GitHub без браузера. В неё включены все поля, поддерживаемые GitHub REST PATCH /user: отображаемое имя, bio, компания, местоположение, сайт, X/Twitter, публичный email и флажок готовности к предложениям о работе.
- Логин и GitHub ID показаны только для чтения. Пароль, аватар, приватные адреса входа и настройки видимости email не могут быть изменены через PATCH /user; нативная форма не обещает неподдерживаемые операции.
- Перед сохранением выполняется проверка полей; отправляются только изменения, успешный ответ обновляет локальный профиль. Запрос требует GitHub App permission Profile: Write. Без нужного доступа показывается текст ошибки, а не переход в браузер.
- Навигационные инструментальные тесты обновлены: пятая вкладка — Настройки, Профиль — подэкран. Добавлен тест списка полей PATCH /user.

Сборки публикуются по зафиксированному процессу BUILD_RELEASE_POLICY.md: тестовый Debug APK в PR, финальный комплект после merge в main.
