# GitHubble Copilot RC2 — этапы 109–116

## 109. Живая диагностика подключения

Добавлен безопасный диагностический экран для выбранного репозитория. Он проверяет Metadata, Agent tasks, Contents, Issues, Pull requests, Actions и доступность `copilot-swe-agent` без создания веток, Issue или задач.

Фактический запуск Copilot из среды сборки не выполнялся: для него нужен пользовательский GitHub-токен, активный Copilot и разрешённый репозиторий.

## 110. Обновление состояния

Экран активной задачи поддерживает ручное обновление и автообновление каждые 15, 30, 60 или 120 секунд. При уходе приложения в фон foreground polling прекращается.

## 111. Системные уведомления

Добавлен `CopilotTaskMonitorJobService` на базе Android JobScheduler и отдельный канал уведомлений. Уведомления создаются при переходах в `completed`, `waiting_for_user`, `failed`, `timed_out` или `cancelled`.

Пользователь выбирает частоту: 15/30 минут, 1/3/6/12 часов.

## 112. Сеансы и артефакты

Отображаются ссылки на журналы сеансов и дополнительные типы результатов: PR, Issue, branch, commit, workflow run, file, session и неизвестные будущие типы с безопасным fallback.

## 113. Архив

Глобальный центр задач поддерживает `is_archived=true`. Публичный REST API пока не публикует mutation для archive/unarchive, поэтому управление выполняется на официальной странице GitHub задачи.

## 114. Custom agents

Добавлен экран `.github/agents/*.agent.md`, выбор профиля при создании задачи и при назначении Issue. В API передаётся имя файла без расширения.

## 115. Матрица разрешений

Перед запуском задачи выполняется read-only preflight. Право `Agent tasks: write` отмечается отдельно: подтвердить его без изменения данных невозможно, поэтому окончательная проверка происходит на запросе Start task.

## 116. RC2-аудит

Собраны APK, AAB и instrumentation APK. Сохранены Device Flow, Keystore, офлайн-очередь, перевод, наблюдение и три тематические иконки с улыбающимся котом.
