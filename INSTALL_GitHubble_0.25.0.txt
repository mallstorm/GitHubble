GitHubble 0.25.0 — установка

Рекомендуемый тест без удаления текущей версии:
1. Установите GitHubble_0.25.0-beta-stage61-72_parallel_release.apk.
2. Он имеет package app.githubble.mobile.beta и появится рядом как GitHubble Beta.
3. Подключите GitHub повторно: хранилища приложений изолированы Android.
4. Настройте переводчик: Настройки → Переводчик.

Основная APK:
GitHubble_0.25.0-alpha-translation-beta-audit_release.apk
Package app.githubble.mobile.

Важно: закрытый ключ, которым была подписана 0.24.0, отсутствует в доступной рабочей среде. Поэтому основная 0.25.0 не обновит 0.24.0 поверх. Для основной сборки нужна однократная чистая установка. До проверки рекомендуется использовать параллельную Beta.

Для ветки 0.25+ создан новый release key. Его fingerprint указан в VALIDATION и отдельной приватной резервной копии.
