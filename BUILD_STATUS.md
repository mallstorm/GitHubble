# Статус сборки GitHubble

Текущая версия: `1.0.0-rc4.2.3` (`versionCode 50`).

RC4.2.1 дополнительно проверяет сортировку по времени активности и точный разбор реальных коммитов. RC4.2 добавляет инструментальные проверки контракта корневых вкладок и фильтров Actions.\n\nRC4.2.3: тесты встроенного коммита (SHA/путь, дедупликация файлов, diff) добавлены в инструментальный набор.\n\nPR в main, push в main и ручной запуск выполняют один и тот же статус **Android checks**:

- unit tests;
- Android Lint для release;
- `assembleDebug` и `assembleRelease`;
- on-device regression suite на Android emulator API 35;
- экспорт точного source archive и SHA-256 **только после push в main**.

При проверке PR и при ручном запуске APK/ZIP-артефакты не публикуются. После Squash and merge GitHub делает одну финальную сборку/публикацию на main. Результаты промежуточных проверок доступны во вкладке Actions и PR, но не являются пользовательским релизом.

Подписанный APK публикуется только при push в `main`. Concurrency отменяет устаревшие запуски одной ветки, когда в неё отправлен более свежий коммит. Workflow требует постоянный PKCS12
keystore и пароли из GitHub Actions Secrets; временный сертификат больше не
создаётся, поэтому несовместимое обновление приложения не может быть выпущено
случайно.

Локальная среда текущего coding-прохода не содержит Gradle/Android SDK. Итоговый
compile gate является GitHub Actions workflow; его результат считается
авторитетным для релизного артефакта.
