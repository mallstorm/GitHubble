# GitHubble RC4.2.3 — встроенная страница коммита

Основа: RC4.2.2 (`77a3aac`). Версия `1.0.0-rc4.2.3`, versionCode `50`.

## Сценарий

Во вкладке «Активность» карточка коммита открывает **нативную страницу внутри GitHubble** вместо браузера. Встроенный просмотр также доступен из списков коммитов репозитория и Pull Request. В верхней части показаны сообщение коммита, автор, локальное время, SHA, родители, суммарные добавления/удаления и число изменённых файлов. Список файлов показывает их статус, путь (включая прежний путь при переименовании), количество добавленных/удалённых строк. Нажатие на файл показывает встроенный unified diff с подсветкой добавленных и удалённых строк, номерами строк и свёрнутым контекстом. Первый файл раскрыт по умолчанию. Дополнительные файлы загружаются на экран порциями по 24.

## Реальные данные

`GET /repos/{owner}/{repo}/commits/{sha}?per_page=100&page=N` с авторизованным GitHub App token позволяет читать и приватные репозитории при наличии `Contents: Read`. При листании сохраняется уникальность файлов, максимум 300 файлов на коммит; неполный результат и ошибка доступа показываются на экране. Никакой HTML или JavaScript из diff не выполняется. Для безопасности длинные патчи ограничены 550 строками/150000 символами, а для бинарного/недоступного patch показывается описание и при наличии ссылки доступен встроенный предпросмотр файла. Кнопка «Открыть GitHub» остаётся только дополнительной.

## Навигация, совместимость, тесты

Кнопка назад возвращает на активность или список коммитов, SHA и репозиторий сохраняются при восстановлении экрана. Ответ другого аккаунта/устаревшего запроса не меняет текущий экран. Добавлены тесты валидации SHA и репозитория, дедупликации файлов, данных status/additions/deletions и парсинга patch. Сохраняется workflow: отдельная ветка, проверочный PR без APK, squash merge и одна финальная APK сборка из main.

### Ограничения и приёмка на устройстве

- Обзор показывает patch, полученный из GitHub API; большие файлы/бинарный diff могут не иметь текстового patch, а длинные патчи сокращаются для экономии памяти.
- Вызов REST commit может возвращать только ограниченное число файлов за один запрос; при >300 файлах просматривается начальный набор и выводится предупреждение.
- Требуется проверить на телефоне реальный приватный коммит GitHubble, длинные файлы, перенос строк, раскрытие другого файла, возврат к активности и офлайн/ошибку 403. Зелёный CI не подтверждает пользовательскую приёмку на Android.
